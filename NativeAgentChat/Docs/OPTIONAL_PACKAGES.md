# Optional packages to add later

The starter project is dependency-light on purpose, so it opens and compiles before external package resolution.

Recommended next additions:

## A2UI Swift Renderer

Use when you want to replace or extend the internal `ChatComponent` renderer with the A2UI protocol.

Package:

```text
https://github.com/BBC6BAE9/a2ui-swift
```

## MarkdownUI

Use when assistant text should support tables, code blocks, links, task lists and richer Markdown.

Package:

```text
https://github.com/FelixLisczyk/swift-markdown-ui
```

## MCP Swift SDK

Use when you want the app to connect to external/local MCP tool servers.

Package:

```text
https://github.com/modelcontextprotocol/swift-sdk
```
